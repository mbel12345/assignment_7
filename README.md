# Project Setup

## Set up Repo
In Github:
Create new repo called assignment_7 and make sure it is public

In WSL/VS Code Terminal:
```bash
mkdir assignment_7
cd assignment_7/
git init
git branch -m main
git remote add origin git@github.com:mbel12345/assignment_7.git
vim README.md
git add . -v
git commit -m "Initial commit"
git push -u origin main
```
